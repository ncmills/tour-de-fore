# Phase 0 — Is this worth it? (Handicap HQ Phase 1)

**Verdict: worth it, and it's the only version that delivers.** Nick directed the split explicitly.

## Cheapest version that would surface the same value
The only cheaper move is a DNS alias `handicaphq.com → tourdefore.com` with no rebrand. That fails every goal: no custom brand, no suite membership, and TDF doesn't become personal. There is no cheap proxy — the value *is* the separation + rebrand.

## Full-plan cost vs cheap-version cost
- Full plan (this doc): stand up a new repo/Vercel/domain, custom design system, rebrand, strip, infra repoint. Large but bounded — mostly a clone + mechanical swaps + one genuine creative block (the design system).
- Cheap version: ~zero, delivers nothing.

## Cost-control lever (the real risk)
The design "moat" motifs can balloon: bespoke per-destination hole-map art, passport-stamp gamification, elaborate yardage-book animation. **Launch ships the token/type/palette reskin + one good yardage-book itinerary component + a generated (not bespoke) contour/hole-map treatment.** Bespoke per-destination art and gamification are backlog, explicitly non-blocking. If the design block runs long, cut to the token+type+primitive reskin and ship — the differentiation survives on palette + scorecard system alone.

## What the cheap version would miss
Everything: the brand, the suite membership (SEO/blog/agents), and the personal-TDF outcome. Nothing to salvage from a cheaper path.

**Proceed.**
